# 科研人员职业能力转化与针对性简历

`tailor-job-resume` 是一个面向科研人员、研究生及准备从学术研究转向业界的 Codex Skill。

它不只根据招聘要求替换简历关键词，而是进一步分析论文和项目中真正使用过的数据、研究方法、模型、软件及工作流程，把这些能力翻译成企业能够理解的语言，并研究求职者还可以进入哪些行业、岗位以及大致薪资范围。

最终输出包括岗位针对性简历、岗位匹配分析和详细求职策略报告。

## 它解决什么问题

科研人员转向业界时，经常遇到以下困难：

- 知道自己的研究主题，却说不清企业为什么需要自己。
- 只寻找与专业名称完全一致的岗位，忽略可以迁移的方法和数据能力。
- 简历列出了论文，却没有展示论文背后的数据处理、建模和分析能力。
- 不熟悉业界岗位名称，不知道自己还可以进入哪些行业。
- 不清楚市场上有哪些真实岗位，也不了解大致薪资。
- 容易把合理推断写成未经证明的能力，造成简历失真。

本 Skill 的目标是先弄清楚求职者真正会什么，再研究这些能力在企业中可以解决什么问题，最后决定简历应该怎么写。

## 固定触发语句

仅在用户明确输入以下完整句子时触发：

> 请根据这个岗位帮我制作针对性简历

普通的简历咨询、文字润色、岗位分析或 HTML 编辑请求不会触发本 Skill。

## 用户需要提供什么

### 必需材料

1. 岗位信息：招聘单位、岗位名称、岗位职责和任职要求。可以是截图、网页、PDF、Word或粘贴文本。
2. 综合简历：支持DOCX、PDF、HTML、Markdown或纯文本。
3. 输出目录：用于保存最终文件。

### 可选材料

- 个人照片。
- 参考简历模板。
- 用户已经保存的论文全文、项目报告或作品。

用户不需要预先整理论文 DOI、摘要、全文、招聘市场数据或薪资数据。Skill 会先自动查找，只有公开渠道无法获得论文全文时，才请求用户上传。

首次分析也不会要求用户先选择行业、企业性质、城市或薪资。对于不了解业界的求职者，过早设置这些条件可能会无意中缩小机会范围。

## 完整工作流程

### 1. 读取岗位与综合简历

拆解招聘单位真正关心的学历、经历、研究能力、数据能力、方法工具、成果表达和协作要求，并从综合简历中提取可核验事实。

### 2. 自动查找论文资料

从综合简历识别论文题目，逐篇查找：

- DOI
- 期刊官网文章页
- 摘要与关键词
- HTML全文或官方PDF
- 补充材料或合法公开版本

中文论文优先进入期刊官网，以完整中文题名查找文章详情页。普通搜索或Crossref没有结果时不会直接停止。

如果公开渠道仍然无法获得全文，Skill 会说明已经找到什么、还缺什么，再请用户决定是否上传论文。

### 3. 提取论文背后的能力

从论文和项目中识别：

- 使用了什么数据，数据从哪里来，规模和时间跨度如何。
- 做过哪些清洗、整理、匹配和指标构建工作。
- 使用了哪些研究方法、模型和算法。
- 使用了哪些软件、语言、程序包和制图工具。
- 如何完成建模、检验、解释、可视化和报告交付。

系统不会只看研究主题。例如：

- GIS和空间计量能力可以迁移到地图、LBS、商业选址、物流和城市计算。
- DID可以迁移到政策效果、业务措施和活动效果评估。
- 聚类分析可以迁移到用户分群、区域分类和市场细分。
- XGBoost和SHAP可以迁移到预测分析、关键因素识别和模型解释。

### 4. 让用户确认事实

最终写作前，Skill 会集中展示三级证据：

- A级：简历、论文或项目材料直接证明。
- B级：由已经确认的方法关系直接推出，并解释为什么。
- C级：有可能使用过，但现有材料不能证明，需要本人确认。

用户只需要确认是否真正使用过某项数据、方法或软件，以及本人在合作成果中承担了什么工作。用户不负责预先判断自己应该进入哪个行业。

例如，论文明确使用SHAP时，可以说明使用了基于Shapley值的解释方法；但不能据此声称求职者独立开发过Shapley算法。使用XGBoost也不能自动证明使用过Python。

### 5. 研究完整职业边界

系统根据已经确认的能力主动识别所有有依据的方向，识别出几个，就研究几个。报告将它们分为：

- 优先尝试：现有履历可以直接支撑。
- 值得拓展：研究主题不同，但数据、方法或软件能力可以迁移。
- 求职边界：补充少量能力或作品后有机会进入。
- 暂不建议：目前缺少关键门槛，转型投入较大。

排序是为了帮助求职者理解先后顺序，不会隐藏已经识别出的方向，也不会因为用户暂时不了解民营企业或陌生行业而提前排除。

### 6. 调查招聘市场与薪资

Skill 会优先搜索近期公开招聘页面、企业官网和招聘公告，不要求用户自己编写爬虫，也不要求提供招聘网站账号、密码或Cookie。

每个方向尽量说明：

- 这类工作平时具体做什么。
- 哪些行业和公司会招聘。
- 常见岗位名称和搜索关键词。
- 市场上最近是否有较多岗位。
- 招聘信息通常给出什么薪资。
- 以当前经历，比较有希望争取什么范围。
- 哪些因素会提高或降低薪资。

薪资会注明城市、时间、样本数量、月薪或年薪口径和信息来源。公开岗位较少时，会明确说明只能作为初步参考，不制造看似精确的数字。

### 7. 生成针对性简历

根据岗位要求和确认后的能力证据，重新组织个人概述、岗位匹配能力、教育背景、重点项目、科研成果、方法技能和荣誉经历。

论文统一使用单行格式：

```text
标题或省略标题｜DOI｜期刊名称（等级）｜第几作者｜年份
```

DOI只显示为可点击的 `DOI` 三个字母。标题过长时自动缩短并以省略号结尾，其余信息保持完整；标题贴齐左侧，年份贴齐右侧。

生成的HTML支持直接修改文字、自动暂存、预览切换、撤销、下载、打印或导出PDF，以及照片大小、位置和裁切调整。

### 8. 生成通俗的求职策略报告

报告像职业顾问面对面解释，而不是写成论文。首页先回答：

- 最值得尝试什么。
- 还可以尝试什么。
- 哪些方向目前不建议。
- 大致可以争取什么薪资。
- 下一步最应该做什么。

随后逐个方向说明匹配证据、真实工作内容、招聘市场、薪资、能力缺口、简历写法、面试重点和补强建议。系统会自动检查报告是否缺少重要部分，并拦截典型的学术化表达。

## 默认交付物

```text
输出目录/
├── 姓名_单位_岗位_可编辑版.html
├── 岗位匹配分析.md
├── 求职策略报告.md
└── 照片文件.jpg    # 仅在照片未嵌入HTML时存在
```

不会额外生成 `姓名_单位_岗位_针对性简历.html`。

对话中还会提供一段结合履历和岗位要求的个人总结。

## 事实边界

Skill允许优化表达、重新排序和解释能力迁移，但不会改变事实性质：

- 不将参与改成主持。
- 不将协助改成独立负责。
- 不虚构数据、软件、奖项、项目级别、论文状态或工作年限。
- 不把团队成果无条件归为个人成果。
- 不把相关方法自动写成熟练掌握。
- 不能确认的内容会进入待确认清单，而不是直接写入简历。

## 隐私保护

本仓库只包含通用规则、脚本和虚构示例，不包含真实客户的姓名、电话、邮箱、照片、简历、论文全文或求职材料。

客户材料不得写入Skill目录或公开仓库。仓库内置隐私扫描脚本，用于检查常见手机号、邮箱、身份证号和本地用户路径。

## 安装

在Codex中提出：

```text
请从GitHub安装这个Skill：https://github.com/Anastasia0521/tailor-job-resume
```

也可以下载仓库，将整个 `tailor-job-resume` 文件夹复制到：

```text
Windows: %USERPROFILE%\.codex\skills\tailor-job-resume
macOS/Linux: ~/.codex/skills/tailor-job-resume
```

安装或更新后，重新启动Codex或刷新Skills。

## 使用方法

在同一个任务中附上岗位材料、综合简历、照片和可选参考模板，然后输入：

```text
请根据这个岗位帮我制作针对性简历
```

Skill会先自动研究简历、论文和市场，在需要确认事实或补充全文时集中提问，确认后再生成最终交付物。
