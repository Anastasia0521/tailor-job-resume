# 岗位针对性简历生成器

`tailor-job-resume` 是一个 Codex Skill。它根据招聘岗位、求职者综合简历、个人照片和可选参考模板，筛选真实且有利的履历证据，生成可直接编辑、打印和导出 PDF 的岗位针对性 HTML 简历。

## 固定触发语句

仅在用户明确输入以下完整句子时触发：

> 请根据这个岗位帮我制作针对性简历

普通的简历咨询、文字润色、岗位分析或 HTML 编辑请求不应触发本 Skill。

## 客户需要提供什么

### 必需材料

1. **岗位信息**：招聘单位、岗位名称、岗位职责和任职要求。支持截图、网页、PDF、Word 或粘贴文本。
2. **综合简历**：支持 DOCX、PDF、HTML、Markdown 或纯文本，应包含可核验的教育、工作、项目、成果和技能信息。
3. **输出目录**：指定最终文件保存位置。

### 可选材料

- 个人照片：JPG、PNG 等常见格式。
- 参考模板：PDF、Word、HTML 或截图。
- 特殊要求：页数、语言、是否隐藏敏感字段、需要突出或弱化的经历等。

缺少照片时生成无照片版本；缺少参考模板时使用正式、克制、适合企事业单位和研究岗位的 A4 版式。

## 能实现什么

### 1. 岗位拆解

将岗位要求拆分为：

- 硬性门槛
- 核心职责
- 研究或业务能力
- 方法与工具
- 领域经验
- 沟通协作
- 优先条件

### 2. 岗位与履历匹配

建立“岗位要求—履历证据—可信程度—表达策略”矩阵，区分直接证据、可迁移证据、弱证据和无证据要求。

### 3. 针对性改写

将相关经历组织为“角色—任务—方法—成果—价值”，优先突出招聘方关心的动作、方法和交付结果，合并重复内容并弱化低相关经历。

### 4. 生成可编辑简历

生成的 HTML 支持：

- 直接点击文字修改
- 自动暂存修改
- 编辑与预览切换
- 撤销全部修改
- 下载修改后的 HTML
- 打印或导出 PDF
- 调整照片宽度与高度
- 调整照片左右及上下位置
- 调整头像裁切位置

### 5. 配套求职内容

同时生成岗位匹配分析，并在对话中提供一段结合履历与岗位要求的个人总结。

## 默认交付物

```text
输出目录/
├── 姓名_单位_岗位_可编辑版.html
├── 岗位匹配分析.md
└── 照片文件.jpg    # 仅在照片未嵌入 HTML 时存在
```

不会额外生成 `姓名_单位_岗位_针对性简历.html`。

## 安装

### 使用 Codex Skill Installer

在 Codex 中提出：

```text

```

### 手动安装

1. 下载或克隆本仓库。
2. 将 `tailor-job-resume` 文件夹复制到 Codex Skills 目录。
3. 重新启动 Codex 或刷新 Skills。

常见个人 Skills 目录：

```text
Windows: %USERPROFILE%\.codex\skills\tailor-job-resume
macOS/Linux: ~/.codex/skills/tailor-job-resume
```

## 使用示例

在同一轮对话中附上岗位截图、综合简历、照片和可选参考模板，然后输入：

```text
请根据这个岗位帮我制作针对性简历
```

Skill 会先检查材料，再分析岗位与履历匹配关系，生成唯一的可编辑 HTML 简历和岗位匹配分析。

## 事实边界

Skill 允许优化结构与语言，但禁止改变事实性质：

- 不将“参与”改写为“主持”。
- 不将“协助”改写为“独立负责”。
- 不虚构数据、奖项、项目级别、论文状态或工作年限。
- 不将团队成果无条件归为个人成果。
- 对冲突日期、模糊角色和无法核实的信息进行待确认标记。

## 隐私保护

本仓库只包含通用流程、脚本和虚构占位示例，不包含任何真实客户的：

- 姓名、电话、邮箱或证件信息
- 个人照片
- 简历原文
- 岗位申请材料
- 本地用户名和个人文件路径

仓库内置 `scripts/privacy_scan.py`，用于检查常见手机号、邮箱、身份证号和 Windows 用户路径等潜在隐私信息。
