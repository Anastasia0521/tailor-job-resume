# 岗位针对性简历生成器

`tailor-job-resume` 是一个 Codex Skill。它根据招聘岗位、综合简历、论文资料和公开招聘市场，识别科研经历背后的数据、方法、软件及可迁移能力，研究求职者的职业边界和薪资，并生成可编辑的岗位简历与详细求职策略报告。

## 固定触发语句

仅在用户明确输入以下完整句子时触发：

> 请根据这个岗位帮我制作针对性简历

普通的简历咨询、文字润色、岗位分析或 HTML 编辑请求不应触发本 Skill。

## 客户需要提供什么

### 必需材料

1. **岗位信息**：招聘单位、岗位名称、岗位职责和任职要求。支持截图、网页、PDF、Word 或粘贴文本。
2. **综合简历**：支持 DOCX、PDF、HTML、Markdown 或纯文本，应包含可核验的教育、工作、项目、成果和技能信息。
3. **输出目录**：指定最终文件保存位置。

### 可选材料

- 个人照片：JPG、PNG 等常见格式。
- 参考模板：PDF、Word、HTML 或截图。
- 特殊要求：页数、语言、是否隐藏敏感字段、需要突出或弱化的经历等。

缺少照片时生成无照片版本；缺少参考模板时使用正式、克制、适合企事业单位和研究岗位的 A4 版式。

## 能实现什么

### 1. 岗位拆解

将岗位要求拆分为：

- 硬性门槛
- 核心职责
- 研究或业务能力
- 方法与工具
- 领域经验
- 沟通协作
- 优先条件

### 2. 岗位与履历匹配

建立“岗位要求—履历证据—可信程度—表达策略”矩阵，区分直接证据、可迁移证据、弱证据和无证据要求。

### 3. 针对性改写

将相关经历组织为“角色—任务—方法—成果—价值”，优先突出招聘方关心的动作、方法和交付结果，合并重复内容并弱化低相关经历。

### 4. 科研论文 DOI 与标题适配

如果综合简历包含科研论文，Skill 会逐篇检索 DOI。中文论文优先根据期刊名定位官网，再以完整中文题名进入官网文章详情页，从 DOI 字段、链接、引用格式、页面元数据或官网 PDF 提取并核验 DOI；不会因 Crossref 或普通搜索无结果就停止。每条论文严格使用单行格式：`标题或省略标题｜DOI｜期刊名称（等级）｜第几作者｜年份`。已验证 DOI 以可点击的 `DOI` 三字母超链接显示；页面不展示 DOI 字符串、完整网址或完整作者名单。

论文完整标题始终保留在 HTML 数据中。页面采用五列网格，标题贴齐左边界，年份贴齐右边界；根据实际可用宽度自动选择英文单词数或中文字符数，以 `…` 截断过长标题，为 DOI、期刊与等级、第几作者和年份预留空间，确保整条论文信息单行且两端对齐。悬停标题可查看完整题目。

简历正文采用正式、精简的陈述句，不使用引号进行强调，也不使用乘号或加号连接描述。论文正式题名等必须忠实保留的名称除外。

### 5. 从论文提取可迁移能力

Skill 会在找到 DOI 后继续查找摘要、官网全文、官方 PDF、补充材料或合法公开版本，从中识别数据来源、数据规模、研究方法、模型算法、软件工具、分析流程和成果形式。只有公开材料仍无法提供全文时，才请求用户上传。

系统不只按论文研究主题推荐岗位，还会把科研方法翻译成企业任务。例如，将空间计量方法联系到区域分析和商业选址，将 DID 联系到政策或业务措施的效果评估，将 GIS 联系到地图、LBS、物流和城市计算。

### 6. 用户确认事实，系统研究方向

交付前集中展示三级能力证据：材料直接证明、由方法关系直接推出、需要本人确认。用户确认本人是否真正使用过相关数据、方法和软件；未经确认的推测不得写入简历。

首次分析不要求用户选择行业、企业性质、城市或薪资，也不让用户自己限定职业方向。系统先研究所有有证据支持的方向，再解释每个方向实际做什么、为什么适合、缺少什么和大致薪资。

### 7. 生成可编辑简历

生成的 HTML 支持：

- 直接点击文字修改
- 自动暂存修改
- 编辑与预览切换
- 撤销全部修改
- 下载修改后的 HTML
- 打印或导出 PDF
- 调整照片宽度与高度
- 调整照片左右及上下位置
- 调整头像裁切位置
- 每份简历使用独立的 v6 浏览器暂存空间，避免旧版论文布局覆盖新内容
- 交付前自动核对论文数量、DOI 链接文字与跳转地址

### 8. 详细求职策略报告

报告覆盖优先尝试、值得拓展、求职边界和暂不建议的全部方向，逐个说明工作内容、行业和公司、匹配证据、招聘需求、薪资参考、能力缺口、简历写法、面试重点和补强建议。报告使用职业顾问式的通俗表达，不用学术术语堆砌权威感。

招聘信息由 Skill 优先通过近期公开页面、企业官网和招聘公告搜索，不要求用户自己写爬虫或提供招聘网站账号、密码、Cookie。

## 安装

### 使用 Codex Skill Installer

在 Codex 中提出：

```text

```

## 使用示例

在同一轮对话中附上岗位截图、综合简历、照片和可选参考模板，然后输入：

```text
请根据这个岗位帮我制作针对性简历
```

Skill 会先检查材料，再分析岗位与履历匹配关系，生成唯一的可编辑 HTML 简历和岗位匹配分析。

## 事实边界

Skill 允许优化结构与语言，但禁止改变事实性质：

- 不将“参与”改写为“主持”。
- 不将“协助”改写为“独立负责”。
- 不虚构数据、奖项、项目级别、论文状态或工作年限。
- 不将团队成果无条件归为个人成果。
- 对冲突日期、模糊角色和无法核实的信息进行待确认标记。

## 隐私保护

本仓库只包含通用流程、脚本和虚构占位示例，不包含任何真实客户的：

- 姓名、电话、邮箱或证件信息
- 个人照片
- 简历原文
- 岗位申请材料
- 本地用户名和个人文件路径

仓库内置 `scripts/privacy_scan.py`，用于检查常见手机号、邮箱、身份证号和 Windows 用户路径等潜在隐私信息。
