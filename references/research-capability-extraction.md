# 科研能力提取

## 获取材料

从综合简历识别全部论文题目。逐篇依次执行：

1. 按 `paper-doi-rules.md` 自动查找 DOI 和期刊官网文章页。
2. 从官网获取摘要、关键词、HTML 全文、官方 PDF 和补充材料。
3. 官网无全文时，查找出版社页面、机构知识库、作者公开版本或其他合法公开来源。
4. 仍无法获得全文时，向用户说明已找到什么、缺少什么，并请求上传全文；用户不提供时只使用公开证据。

不得要求用户预先整理 DOI、摘要或全文。不得绕过访问控制或把论文上传到公开仓库。

## 能力卡片

逐篇记录数据类型与范围、研究方法、模型与算法、软件与程序包、完整分析流程、成果形式、可迁移能力、企业应用场景和证据来源。

不要只按研究主题匹配岗位。优先识别数据、方法、软件和完整分析流程，并把科研语言翻译成企业任务语言。

- 空间计量模型 → 区域关联分析、商业选址、市场覆盖与空间外溢识别。
- DID → 政策或业务措施实施前后的效果评估。
- GIS → 位置数据处理、地图分析、LBS、物流与城市计算。
- 聚类分析 → 用户分群、区域分类和市场细分。
- XGBoost → 分类预测、风险识别和关键因素分析。
- SHAP → 使用基于 Shapley 值的解释方法说明不同变量对模型结果的贡献。

技术关系可以用于准确解释已确认方法，但不得升级为无证据的熟练程度或独立开发经历。
