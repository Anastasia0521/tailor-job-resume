# 论文 DOI 与标题规则

## DOI 检索顺序

先判断论文语言。中文期刊论文必须优先执行期刊官网路径，不得因 Crossref 或普通搜索无结果就判定无 DOI。

### 中文期刊官网路径

1. 从简历提取完整中文题名和期刊名，去除书名号但保留正式题名。
2. 搜索期刊名加“官网”，确认网站由期刊编辑部、主办单位或正式期刊平台运营；排除采集站、文库、百科和下载站。
3. 使用 `site:官网域名 "完整中文题名"` 精确检索。无结果时进入官网过刊目录或站内检索，按题名、作者、年份逐步缩小范围。
4. 打开官网文章详情页，不停留在搜索结果摘要、目录页或第三方数据库页面。
5. 依次从详情页的 DOI 字段、`doi.org` 链接、引用格式、页面元数据 `citation_doi` 或 `DC.Identifier` 提取 DOI。
6. 详情页未显示时，打开官网 PDF，检查首页页眉、页脚、题名信息或引用信息中的 DOI。
7. 用官网页面核对题名、作者、期刊和年份，再访问 `https://doi.org/<DOI>` 验证可解析性。
8. 在工作数据的 `doi_source_url` 保存官网文章页或官网 PDF 地址，作为核验留痕；该地址不在简历中展示。

### 外文与补充路径

1. 使用完整论文题目搜索出版社官方网站或期刊论文页。
2. 使用 Crossref 按题目检索并查看返回元数据。
3. 必要时使用 Google Scholar、PubMed、Web of Science、CNKI 等发现候选记录，但中文论文最终优先回到期刊官网核验，外文论文回到出版社或 Crossref 核验。

## 匹配要求

写入 DOI 前至少满足：

- 标准化标题高度一致；忽略大小写、标点、连字符和多余空格后不应出现实质差异。
- DOI 对应记录的作者、期刊或年份至少有一项与简历信息一致。
- 候选记录之间不存在冲突。

检索结果不确定、论文尚未正式注册 DOI、仅有预印本标识或题目发生变更时，不得推断。将状态写入岗位匹配分析的待确认项，不在简历中显示“DOI 未找到”。

## DOI 格式

- 保存为 `10.xxxx/...`。
- 去除 `https://doi.org/`、`http://dx.doi.org/` 和 `doi:` 前缀。
- HTML 链接目标：`https://doi.org/10.xxxx/...`。
- 页面只显示 `DOI` 三个字母，不显示 DOI 字符串或完整网址。
- 链接必须可点击，并能直接打开对应论文页面。

## 论文字段

每篇论文必须单独保存以下字段，不得塞入一个自由文本字段：

- `title`：正式完整题名。
- `doi`：核验后的规范 DOI；未确认时留空。
- `doi_source_url`：用于核验 DOI 的期刊官网文章页、官网 PDF、出版社页面或 Crossref 记录地址；不在简历中显示。
- `journal`：期刊正式名称。
- `level`：CSSCI、SSCI、SCI、核心期刊或用户材料中明确给出的其他等级；无法核实时写“待确认”，不得推断。
- `author_rank`：填写求职者在该论文中的署名顺序，如“第一作者”“第二作者”“共同第一作者”。不得显示完整作者名单。
- `year`：正式发表年份；在投或录用论文按真实状态处理，不得虚构年份。

期刊、等级、第几作者和年份必须始终显示。字段无法从材料或可信来源核实时，将值写为“待确认”，并同步列入岗位匹配分析，不得直接省略字段。

## 标题显示

- 数据中保留完整标题。
- HTML 根据论文标题行的实际可用宽度自动决定保留词数或字符数。
- 英文标题只在单词边界截断；中文标题只在字符边界截断。
- 发生截断时以单个省略号 `…` 结尾。
- 整条论文严格使用 `标题或省略标题｜DOI｜期刊名称（等级）｜第几作者｜年份`，全部保持一行。
- `DOI`、期刊名称与等级、第几作者和年份优先完整保留；只有标题可以自动截断。
- 标题左边缘与论文行左边缘对齐，年份右边缘与论文行右边缘对齐，形成两端对齐。使用五列布局 `minmax(0, 1fr) auto auto auto auto`，不得用空格模拟对齐。
- 鼠标悬停标题时应能通过原生提示查看完整标题。
