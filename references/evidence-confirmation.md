# 能力证据确认

在生成最终简历和求职策略报告前完成一次集中确认。只让用户确认事实，不让用户预先选择行业、岗位或企业类型。

## 三级证据

- A级：简历、论文、项目材料或用户陈述直接证明。展示证据摘要，允许用户纠正。
- B级：由已确认方法的定义或必要组成部分直接推出。解释推导关系，允许接受、修改或拒绝。
- C级：有可能使用过但公开材料不能证明。必须询问用户，确认前不得写入简历事实。

论文明确使用 SHAP 时，可以写使用基于 Shapley 值的解释框架；不能据此声称独立实现 Shapley 算法。使用 XGBoost 不能自动证明使用 Python 或 SHAP。

一次性按论文或项目分组展示已有材料证明的能力、方法关系可以直接说明的能力、需要本人确认的能力，以及无法获得全文的论文。用户可以确认、否认、改写熟练程度、补充场景或选择不写入简历。没有回复的 C 级能力视为未确认。

不要在首次交互中询问城市、薪资、企业性质或行业偏好。先完成不设限的职业探索，帮助用户理解可能性后再讨论取舍。
