# 岗位匹配与改写框架

## 分解岗位

将岗位内容整理为：

1. 硬性门槛：学历、专业、年限、年龄、证书等。
2. 核心职责：入职后需要持续完成的任务。
3. 方法能力：研究、分析、工具、写作、项目管理等。
4. 领域经验：行业、政策、客户、业务或研究主题。
5. 协作表达：团队、汇报、会议、外部沟通。
6. 优先条件：党员、奖项、成果、特定机构经验等。

## 证据分级

- A：直接完成过同类任务，并有角色、方法或成果证据。
- B：完成过相邻任务，能力可迁移且逻辑清楚。
- C：仅课程、工具或自我评价支持。
- D：无证据或存在冲突。

简历正文优先写 A，选择性写 B，C 只作技能补充，D 不写并在匹配分析中提示。

## 改写结构

使用“角色—任务—方法—成果—价值”。量化数据只能来自原始材料。避免“负责相关工作”“能力较强”等无法验证的表述。

## 排序

按“岗位直接相关度 > 证据强度 > 影响范围 > 新近程度”排序。相似项目合并，避免同一能力重复证明。
